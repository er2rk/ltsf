For each stable workflow, an annotated git tag is created in both repositories. 
[Git Tagging](https://git-scm.com/book/en/v2/Git-Basics-Tagging) for reference.
`git tag -a <version_number> -m <message>` to tag the exact commits. 
`git tag` to see a list of previous tags.
`git show <version_number>` to see tag data.
